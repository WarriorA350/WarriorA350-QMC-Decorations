# Service Record Website

This is a visual website based on the `awards-tui` repository's award catalog/image map and the supplied service-record screenshots.

## Customize

Open `data.js` and set:
- `username`
- profile fields
- `profileImage`
- `awards` — one object per award actually earned
- `operations` — OSB/JSA/ASD/SWA/KOSOVO/AFGHANISTAN/IRAQ records

Award images can use an `imageKey` matching `audits/image-map.json` from the original repository.

## Run

Open `index.html` in a browser. No build step is required.

## GitHub Pages

Upload these files to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
